Sensor-Lean
BMS Technology

Electric vehicle battery management systems rely heavily on onboard voltage sensors, creating reliability concerns when sensors fail. SlimBatt reduces dependency on onboard sensors by combining hardware sensor reduction with simplified state estimation algorithms—retaining accuracy while cutting complexity.

The Problem & Our Solution

Addressing hardware complexity with intelligent, algorithm-driven estimation.

warning

The Problem

  • close Relying on onboard voltage sensors for every cell decreases BMS reliability when sensors fail and increases computational load.
  • close Existing literature typically reduces either hardware complexity or software complexity, but rarely addresses both together.
memory

Our Solution

  • check Reimagines the entire battery pack as a single "average" model, estimates state over the average model, and distributes the estimate to each cell.
  • check Simultaneously reduces sensor count and algorithm complexity, increasing fault tolerance and reducing development overhead.
